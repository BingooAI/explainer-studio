# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this
project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Note that four things are versioned independently — packages, the `explainer/v1` document
format, rendering profiles, and individual kits. See
[ENGINEERING.md §7](docs/ENGINEERING.md) for which is which and what a break means in each.

## [Unreleased]

### Added

- Monorepo tooling — pnpm workspaces, Turborepo, TypeScript strict, ESLint, Prettier

  licence compatibility checks
- Open-source project furniture and contribution guidelines
